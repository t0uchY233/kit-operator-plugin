# Оператор КИТ

Плагин для ChatGPT desktop и Codex с одним навыком помощника операторской компании по методике КИТ, без MCP-сервера; [описание агента](plugins/operator-kit/skills/operator-kit/agent/ПРОЧТИ.md).

`agent/` — сборочная копия исходного проекта агента. Её `ПРОЧТИ.md` описывает исходный проект целиком; тестов (`проверка/`), сборщика и навыка Claude Code в этом репозитории нет. Вручную `agent/` не правят: правки делаются в исходном проекте и переносятся сборщиком.

## Установка из GitHub

```sh
codex plugin marketplace add t0uchY233/kit-operator-plugin
```

Репозиторий приватный: нужен доступ к нему и вход в GitHub (`gh auth login`). Перезапустите ChatGPT desktop → Plugins → источник «КИТ — оператор» → Install. В новом чате вызовите `@operator-kit` или задайте обычный вопрос о проекте или составе оператора.

## Локальная установка без GitHub

```sh
codex plugin marketplace add ./путь/к/chatgpt-plugin
```

Затем перезапустите ChatGPT desktop и установите плагин через Plugins, как описано выше.

## Обновление у пользователя

```sh
codex plugin marketplace upgrade kit-operator
```

Затем перезапустите ChatGPT desktop.

## Обновление у сопровождающего (нужен исходный проект агента)

Поправьте знания в исходной папке `оператор-агент/`. Из её родительской папки выполните:

```sh
python3 оператор-агент/собрать_плагин.py
```

Затем сделайте commit и push репозитория плагина.

## Ограничения

Запуск Python-скрипта зависит от среды; без него агент считает вручную и отмечает это в ответе. Знания содержат черновик методики; версия указана в шапке [методики](plugins/operator-kit/skills/operator-kit/agent/знания/методика.md).
