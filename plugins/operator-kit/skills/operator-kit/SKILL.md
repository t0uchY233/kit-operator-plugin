# Помощник оператора по методике КИТ

Явные указания пользователя в чате важнее этого навыка, но запреты ИНСТРУКЦИИ не выдумывать данные проекта и не говорить от имени автора остаются в силе.
Все пути указаны от папки навыка.

1. Прочитай целиком `agent/ИНСТРУКЦИЯ.md` и действуй по ней с учётом приоритета выше: там роль, режимы, запреты и формат ответа.
2. Прочитай `agent/знания/методика.md` и `agent/анкета_проекта.md` целиком.
3. `agent/знания/правила.md` большой. Не читай его подряд: перед ссылкой на правило найди его по идентификатору (`### RV07-1.`) и сверь условие, действие и цифры. `agent/знания/глоссарий.md` открывай для определений терминов и ролей.
4. Данные проекта бери из сообщения пользователя и из файлов, которые он назвал. Ничего о проекте не додумывай.
5. Если пользователь просит сохранить разбор, отдай файл `<Проект> — разбор агентом (черновик).md`, если среда умеет отдавать файлы; иначе дай текст в ответе.
6. Для расчёта оператора (режим 4) прочитай `agent/знания/параметры_расчёта.md` и раздел 6 анкеты. Сохрани профиль в JSON во временной папке среды и запусти `python3 -I agent/расчёт_оператора.py <профиль.json>` из папки навыка (или укажи абсолютный путь к скрипту внутри неё). Числа бери из вывода, сам не пересчитывай. Код завершения 2: спроси у пользователя то, что перечислила программа. Если код запустить нельзя, считай вручную по шагу 2 режима 4 в `agent/ИНСТРУКЦИЯ.md` и по `agent/знания/параметры_расчёта.md`; прямо напиши, что расчёт ручной. `agent/знания/функции_оператора.md` большой: открывай его по коду функции (`### Ф30.`), когда нужны правила или периодичность. Образец ответа: `agent/примеры/расчёт_условный_подрядчик.md`.
