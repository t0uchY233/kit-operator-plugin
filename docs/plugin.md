# Оператор КИТ

Издатель: **Сардор** (GitHub: [t0uchY233](https://github.com/t0uchY233)).

Бесплатный плагин для ChatGPT и Codex, помогающий операторским компаниям работать по методике КИТ на основе материалов С. Н. Веселкова.

Плагин помогает разобрать проект подрядчика, выявить недостающие данные, предложить следующие действия, составить задачи со ссылками на правила и рассчитать роли и число позиций оператора.

Знания основаны на черновике методики и не охватывают все статьи и видео автора. Расчёт использует включённый Python-скрипт, если среда поддерживает выполнение; иначе помощник помечает расчёт как ручной. Плагин не рассчитывает оклады, стоимость команды, трудозатраты и вердикт чек-листа «72 часа», не даёт юридических заключений и не говорит от имени автора методики.

Плагин содержит один навык, не использует MCP-сервер и не передаёт переписку в сервисы издателя. Обработка чата зависит от используемого продукта OpenAI и его настроек.

Поддержка: [создать обращение в GitHub Issues](https://github.com/t0uchY233/kit-operator-plugin/issues). Обращения публичные: не размещайте в них пароли, персональные данные или конфиденциальные материалы проекта.

Исходный код и инструкции установки: [репозиторий](https://github.com/t0uchY233/kit-operator-plugin).
